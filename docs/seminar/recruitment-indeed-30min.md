# 採用セミナー（30分）構成案 — Indeed 中心

_対象時間: 30分（Q&A別枠）／目的: **情報提供**（売り込みではない）_

---

## 0. 前提

### 聴衆は2タイプ混在

| タイプ | Indeed の使い方 | 応募の先にあるもの |
|---|---|---|
| **A. 経営者陣** | 自社の採用 | 応募 → 面接 → 入社 → 定着 |
| **B. 人材紹介会社** | 求職者の集客 | 応募 → 登録面談 → 求人紹介 → 決定 |

**2本の話に分けてはいけない**。30分では持たないし、どちらの参加者も半分しか聞かなくなる。

### 貫くフレーム（導入で宣言する）

> **「表示されて、クリックされて、応募されるまでは、AもBも完全に同じ話です。違うのは応募の“後ろ側”だけです」**

- 第1部〜第3部前半（原稿・タイトル・給与・運用）は **完全に共通**。
- 分岐するのは **応募後のファネル** と **許容単価の計算式**。ここだけ「Aの場合／Bの場合」で並べる。
- スライドの隅に **A / B のマーク**を入れると迷子が出ない（共通パートは両方点灯）。

### 目的が「情報提供」であることの設計への影響

- 自社紹介は **30秒**。締めの売り込みも **1分以内、1回だけ**（実質は資料に1行）。
- 代わりに **持ち帰り資料の質**に全振りする。参加者が翌日1人で実行できる状態がゴール。
- 情報提供型は、売り込まないほうが後から相談が来る。

### 数字と最新性の扱い

- 実データを出せるので、**目安ではなく実測を主役にする**（§10 に必要な数字のリスト）。
- Indeed の仕様・課金メニュー・**審査基準**・無料掲載の露出条件は変更が早い。資料に **「◯年◯月時点」** を入れ、単価は「当社支援実績のレンジ」と限定する。
- 法令（職業安定法の明示義務、労働条件明示ルール、年齢・性別の制限禁止）は **登壇前日に一次情報で再確認**。特に §3 と §6-9 は規制が絡む。

## 2. 導入（0:00–2:00）

1. 自己紹介30秒（社数・職種・エリアの3点だけ）。
2. **聴衆の前提を先に言い当てる**：「今日は自社で採りたい方と、紹介事業の集客で使っている方がいらっしゃいます」→ §0 の共通フレームを宣言。
3. 問いかけ：**「自社の求人を、いま、スマホで求職者と同じ言葉で探して、見つけられますか？」**
   - 出てこないなら原稿の巧拙以前に露出がゼロ。最後の3ステップで回収する。
4. 今日持ち帰る3つ：
   1. **止まるリスクを先に潰す**。運用の巧拙より、止まらないことが先
   2. 払っていい応募単価は **自社の数字から計算できる**（相場から入らない）
   3. **応募後の電話が、広告費より効く**

### 登壇チップス

- 冒頭に会社紹介を長くやると、そこで離脱される。「今日は網羅しません。3つだけです」と宣言するとメモの取り方が変わる。

## 3. 第0部：止まったら全部ゼロ（2:00–5:00）★冒頭に置く

### なぜ冒頭か

> **「今日は原稿と運用の話をしますが、その前に。掲載が止まったら、原稿の出来も予算も全部ゼロになります。しかも、止まるのは配信が一番回っているときです。」**

この入り方をすると、以降の「1求人1職種」「タイトルの書き方」が**単なるコツではなくリスク管理として聞かれる**。特にBタイプ（紹介会社）は構造的にリスクが高いので、真剣に聞く。

**重要な前置き**：Indeed の審査基準とポリシーは変わる。ここは「**よく止まっているパターン**」として実務の経験から話し、断定しない。最新の可否は必ず確認する、と明言する。

### 3-1. 止まる・出なくなる代表パターン（2分）

| パターン | 何が起きるか | なぜ危ないか |
|---|---|---|
| **実在しない求人の常時掲載** | 非表示・掲載停止 | 「とりあえず母集団確保」で募集していない職種を出し続ける。Bタイプがやりがち |
| **重複投稿** | 後から出したものが非表示 | 直接投稿とサイト連携の二重、代理店と自社の二重、複数アカウント |
| **1求人に複数職種・複数勤務地** | 品質低下・非表示 | 原則1求人1ポジション。検索にも当たらない |
| **タイトルの煽り・記号・絵文字・給与の詰め込み** | 審査落ち・品質低下 | 「急募!!!」「月収50万可能★」 |
| **実態と異なる条件** | 停止リスク | 歩合の上限値を月収として書く、固定残業代を隠す |
| **年齢・性別・国籍の制限表現** | 停止＋法令違反 | 「若い方が活躍中」「主婦歓迎」「日本人のみ」。**法律で原則禁止**（後述） |
| **Indeedの応募フローを迂回する外部誘導** | 停止リスク | 「まずLINE登録してください」「詳細は自社サイトへ」。Bタイプが特に注意 |
| **そもそも求人でないもの** | 一発停止級 | 業務委託の勧誘、スクール・セミナーへの誘導、副業商材 |
| **多重アカウント／再登録** | アカウント停止の連鎖 | 止まったので支払い手段を変えて別アカウントで出す、が最悪手 |
| **募集終了求人の放置** | 実在性の疑義 | クローズを忘れる。これが積み重なると信用を落とす |

### 3-2. 一番痛いのは「アカウント単位で止まる」こと（0.5分）

- 1つの求人の問題で **アカウント全体・配信全体が止まる**ことがある。1職種の不注意で全職種の応募が0になる。
- 止まるのは繁忙期。**採用したい時期に止まると、機会損失が広告費の何倍にもなる**。
- 復帰は即日ではない。再審査を待つ間、打ち手がない。

### 3-3. 法令が絡む部分（0.5分）— ここは正確に

- **年齢制限は原則禁止**（労働施策総合推進法。旧・雇用対策法）。例外は限定列挙で、認められる場合も理由の明示が必要。「若手が活躍」「20代中心の職場」も実質的な年齢制限と取られうる。
- **性別の制限も原則禁止**（男女雇用機会均等法）。「女性スタッフ募集」「主婦歓迎」は表現を変える（「シフト相談可」「家庭と両立している方が多い」等、事実の記述にする）。
- **国籍による募集制限**も不適切。在留資格上の就労可否は「必要な資格」として書く（§6-10）。
- **労働条件の明示**（就業場所・業務の変更の範囲、固定残業代の内訳等）。2024年に明示事項が拡大している。**要件は登壇前日に一次情報で確認**。
- Bタイプは加えて **有料職業紹介事業の許可番号・事業者名の明示**、**求職者から手数料を取らないことの明示**（詳細は §6-9）。

### 3-4. 予防のチェックリスト（0.5分）— 配布資料に入れる

1. **掲載前チェックシートを1枚作る**（NGワード表＋必須記載項目）。属人的にやらない
2. **NGワードを機械的に潰す**：「若手」「主婦」「日本人」「急募!!」「月収◯万可能」等をリスト化して検索する
3. **投稿経路を1本に統一**。代理店に任せるなら、自社側は出さない。二重投稿は事故で起きる
4. **募集終了したら必ずクローズ**。カレンダーに月1回の棚卸しを入れる
5. **応募はIndeedのフローで受ける**。外部誘導しない
6. **止まったら推測で全面書き直しをしない**。通知の内容に沿って1箇所ずつ直して再申請する（全部変えると原因が分からなくなり、次も止まる）
7. **Indeed 1本足にしない**。求人ボックス・スタンバイ・自社採用ページ・ハローワークのどれかを常時走らせておく。**止まった日に採用が完全停止しない状態を作るのが唯一の本当の保険**

### 締めの一言

> **「止まらないための作業は、全部“いい求人を書くための作業”と同じです。実在する募集を、1職種ずつ、事実で書く。それだけです。」**

→ これで第3部の原稿論に自然につながる。

## 4. 第1部：採用の原理原則（5:00–10:30）

### 4-1. 求人広告はマーケティングと同じ構造（1.5分）

求職者＝顧客、求人票＝商品ページ、面接／登録面談＝商談。

```
                       表示（インプレッション）
                         → クリック
                           → 応募            ← ここまでA・B共通
                             ↓
        ┌────────────────────┴────────────────────┐
   【A 自社採用】                          【B 紹介会社の集客】
   連絡がつく                               連絡がつく
     → 面接設定 → 面接実施                    → 登録面談の設定 → 登録面談実施
       → 内定 → 承諾 → 入社                    → 求人紹介 → 企業面接 → 決定
         → 定着（3ヶ月・1年）                     → 入社後フォロー
```

**言い切るポイント**：「応募が来ない」の実態は、多くが「応募は来ているが、その先で落ちている」。Bタイプは段が1つ多いので、**同じ応募数でも成果が出にくい構造**になっている。後段の歩留まりを見ずに予算を増やすのが、いちばん金を捨てる。

### 4-2. ★許容応募単価を自分で計算する（2.5分／ワーク込み）

**相場を聞きに来た人に、計算式を渡して帰す。**

```
応募1件の価値 = 1件の成果額 × 応募→成果の転換率
許容応募単価（CPA）= 応募1件の価値 × 許容率（例 20〜30%）
```

**Aタイプ（自社採用）**
```
1件の成果額 = その人が1年で生む粗利（または採用できないことで失う額）
転換率       = 応募 → 入社 の率
```
- 「採れないことで失う額」で計算させると経営者陣に刺さる（機会損失・既存社員の残業代・断った案件）。

**Bタイプ（紹介会社の集客）**
```
1件の成果額 = 1決定あたりの手数料
転換率       = 応募 → 決定 の率（段が多いのでAより一桁小さい）
```
- **Bタイプの参加者は自分の転換率を知らないことが多い**。「応募→登録面談実施率」「登録→決定率」が出せないなら、そこが最初の宿題。

**30秒ワーク**：手元に「1件の成果額」「転換率」だけ書き出してもらう。中盤に手を動かさせると集中が戻るし、式が記憶に残る。

**締め**：「相場より高いか安いかは意味がありません。**自社の許容単価より高いか安いか**だけです」

### 4-3. 採用競合は同業他社ではない（1分）

- 求職者から見た競合は **同じ商圏・同じ給与帯の全求人**。飲食の競合はコンビニでも倉庫でもある。
- Bタイプはさらに **紹介会社同士でクリック単価を押し上げ合っている**（同じ求職者を同じキーワードで取り合う）。だからBは単価競争ではなく**原稿とスピード**で勝つしかない。
- **実際の検索結果画面を見せる**のが最も効く（スクショ推奨・§9）。

### 4-4. 「採用できない」の8割は人物像が決まっていない（0.5分）

Must が5個以上あれば、それは採用ではなく奇跡待ち。

| 区分 | 内容 | 例 |
|---|---|---|
| Must | ないと採用しない | 週4日以上・土日どちらか出勤可 |
| Want | あると嬉しい | 経験1年以上・普通免許 |
| Negative | あると採らない | 直近3年で短期離職3社以上 |

## 5. 第2部：媒体の地図とIndeedの位置づけ（10:30–15:00）

### 5-1. 媒体は5種類しかない（1.5分）

| 種類 | 例 | 課金 | 向き |
|---|---|---|---|
| 求人検索エンジン | Indeed / 求人ボックス / スタンバイ | クリック課金が中心 | 常時募集・複数職種・地場・**集客用途** |
| 求人サイト | タウンワーク / マイナビ系 / doda 等 | 掲載課金 | 短期集中・ブランドのある募集 |
| 人材紹介 | エージェント | 成果報酬（理論年収の3割前後） | 採用難職種・急ぎ・少数 |
| ダイレクト・SNS | スカウト媒体 / X / Instagram | 月額＋工数 | 母集団が薄い職種・認知 |
| リファラル・ハローワーク・自社サイト | — | ほぼ無料 | 土台。放置されがち |

**言い切るポイント**：課金形態が違うだけで、全部「求職者との接点を買う」こと。値段ではなく **募集の頻度** で選ぶ。年1回なら掲載課金、年中募集ならクリック課金。

> Aタイプへの補足：この表の「人材紹介」は今日の聴衆Bの事業。**採用チャネルとして併用する前提**で話すと会場が対立しない。

### 5-2. なぜ Indeed から始めるのか（1.5分）

1. **求職者の入口としての規模**。求人サイトに載せた求人も結局 Indeed 経由で見られていることが多い。
2. **クリック課金なので少額から始めて止められる**。掲載課金と違い、失敗が1ヶ月固定されない。
3. **無料掲載の枠がある**（露出は絞られる傾向。最新条件は要確認）。0円で原稿の型を作れる。
4. **数字が見える**。表示・クリック・応募が見えるので、ファネル分解がそのまま運用になる。

正直に言う：**Indeed は仕様変更が早い**。無料掲載の見え方、課金メニュー、審査基準は都度変わる（§3 のリスクもここに連動する）。「◯年◯月時点」と添えて、細かい最新仕様は質問で受ける。見栄を張ると信頼を落とす。

### 5-3. 掲載の2経路（1分）

- **直接投稿**：Indeed 上で求人を作成。今日から始められる。まずこれ。
- **サイト連携（クロール）／ATS連携**：自社採用サイトの求人を拾わせる。自由度と資産性が高いが立ち上げに時間がかかる。**両方やると §3-1 の重複事故が起きる**ので、経路は1本に決める。
- 順番は **直接投稿で勝ちパターンを作る → 採用サイトに移す**。逆をやると効果の出ない採用サイトに数十万円かける。

### 5-4. 費用の考え方（0.5分）

- クリック単価は職種・エリア・時期で大きく動く。**見るべきは単価ではなく応募単価と成果単価**（§4-2 に戻す）。
- 1〜3月・9〜10月は求人が増えて競合が強い。**採りたい時期の1ヶ月前に原稿を仕上げる**。
- ここに **自社支援実績のCPAレンジ**を職種別で出す（§10-2）。

## 6. 第3部：Indeed 実践施策（15:00–26:00）★本編

### 6-0. ★全体の見方：3段＋1の分解（1.5分）

**配布資料の目玉。「どこが悪いか」は数字で必ず分かる。**

| 症状 | 見る数字 | 原因の在り処 | 触る場所 |
|---|---|---|---|
| そもそも表示されない | 表示数 | 検索に当たっていない／予算／**停止・非表示（§3）** | 職種名・勤務地・予算・掲載状態 |
| 表示はされるがクリックされない | CTR | 一覧画面で選ばれていない | タイトル・給与・会社名の見え方 |
| クリックされるが応募されない | 応募率（CVR） | 詳細ページで離脱 | 本文冒頭・写真・応募フォーム |
| 応募は来るが成果にならない | A: 面接実施率／B: 登録面談実施率・決定率 | 応募後の対応 | **電話（§6-7）**・日程調整・ミスマッチ |

- **触る順番**：`掲載状態の確認 → 原稿 → 対象の拡大（勤務地/雇用形態/時間帯/給与レンジ）→ 予算`。**予算増額は最後**。
- 「表示が急に落ちた」ときは原稿を直す前に **§3 の停止・非表示を疑う**。これを知らないと原稿を無駄にいじり続ける。
- ここに自社実績の改善事例（§10-1）を1つ当てる。

### 6-1. 掲載の型（1分）

- **1求人＝1職種＝1勤務地**。「ホール・キッチン・配達スタッフ募集！」は検索に当たらず、クリックの質も落ち、§3 のリスクにもなる。
- 複数店舗・複数エリアは分けて出す。勤務地は **番地まで**（エリア検索・通勤時間の絞り込みに効く）。
- 同一内容のコピー投稿はしない。分けるなら中身も変える。

### 6-2. タイトルが9割（1.5分）

型：**【職種名】＋【雇用形態】＋【勤務地】＋【訴求を1つだけ】**

- 良い例：`調理補助（パート）／◯◯市△△町・週3日〜・未経験可`
- 悪い例：`一緒に働きませんか？アットホームな職場です！！`
  - 「アットホーム」「明るい職場」は検索されない語。1文字も仕事をしていない。
- **求職者が検索する語を使う**：「軽作業」「ホールスタッフ」「2tドライバー」「介護職員初任者研修」。社内呼称（「サービスクルー」等）は通じない。
- 記号の乱用・煽り・絵文字は避ける（§3-1 のとおり審査でも不利）。
- 訴求は1つ。3つ入れると何も残らない。

### 6-3. 給与欄（1.5分）

- **「応相談」「当社規定による」は最悪手**。給与での絞り込み検索から丸ごと外れる。
- 必ず数値、かつ幅で（例：時給1,150円〜1,400円）。上限には根拠（経験・資格）を添える。
- 月給なら **固定残業代は時間数と金額を明記**。訴求以前に法令上の明示事項。
- **歩合の上限を月収として書かない**（§3-1 の停止パターン）。「平均◯円・上位◯%で◯円」と分布で書く。
- 「昇給あり」より「入社1年で時給+50円が◯%」。**数字と実績で書く**。

### 6-4. 本文の並び順（1.5分）

求職者の意思決定順に並べる。これがそのまま本文構成。

1. **勤務地**（通えるか）→ 2. **給与**（生活できるか）→ 3. **時間・シフト**（続けられるか）→ 4. **仕事内容**（できるか）→ 5. **人・雰囲気**（安心か）

- **冒頭150文字で「誰に・何を・いくらで」を言い切る**。スマホで最初に見えるのは数行。会社沿革から始めない。
- 効くブロック：`1日の流れ`／`入社後3ヶ月のイメージ`／`よくある質問`／`先輩の声`。
- **ネガティブ情報を先に出す**（体力を使う／土日出勤あり／立ち仕事）。応募数は少し減るが、**後段の実施率と定着率が上がって成果単価は下がる**。§4-1 のファネルに接続。
- 写真は**実際の職場・実際の人**。ストックフォトは見抜かれる。動画は差がつく。

### 6-5. 応募フォームの摩擦（0.5分）

- 追加質問は **3つまで**。多いほど落ちる。
- **「履歴書必須」は応募率を大きく下げる**。書類は面談時でよい。
- 応募完了後の自動返信に **次に何が起きるか**（誰から・いつ・どの手段で連絡が来るか）を書く。「**これから◯◯（担当者名）よりお電話します**」と書いておくと、次の電話に出てもらえる率が上がる。

### 6-6. 運用（1分）

- 1職種あたり少額の日予算で **2週間テスト**。効果のない原稿に予算を足しても効果は出ない。
- **触るのは1回1箇所**。同時に複数変えると何が効いたか分からない。
- **週1回15分の定例**で数字を見る（表示・クリック・CTR・応募・CPA・**掲載状態**）。運用しているかどうかが最大の差。
- 企業の口コミ評価は放置しない。応募直前に見られている。

### 6-7. ★応募後の電話（2分）— 本日いちばん費用対効果が高い話

> **「広告費を1円も増やさずに採用数を増やす方法が1つだけあります。応募が来たら、すぐ電話することです。」**

**なぜ効くのか**

- **応募ボタンを押した直後が、その求職者があなたの会社を一番考えている時間**。時間が経つほど熱は下がり、他社が先に電話する。
- 求職者は複数社に同時応募している。**最初に電話が通じた会社が、そのまま面接に進む**。
- メールと自動返信だけでは動かない。届いていても読まれない、読んでも返信しない。**電話は即決できる唯一の手段**（その場で面接日が決まる）。
- Bタイプはさらに効く。求職者は複数の紹介会社に同時登録しているので、**先に面談を組んだ会社の案件で決まる**。

**スピードの基準**

- **1時間以内**。理想は応募通知を見て **5分以内**。
- 翌日の連絡は、つながる前提で考えてはいけない。
- 応募通知を **Slack／LINE／メールの共有箱に飛ばして、誰でも取れる状態**にする。担当者1人の受信箱に入れると、その人が休みの日の応募が死ぬ。当番制でよい。

**出ない前提で設計する（ここが実務の核心）**

- 1回目でつながるのは半分以下。**時間帯を変えて2〜3回**かける（当日夜・翌朝・翌夕）。
- **在職者は昼休み（12〜13時）と夕方（18〜20時）**がつながりやすい。日中の架電だけで「連絡がつかない人」と判断しない。
- **知らない番号・非通知には出ない**。だから **SMSを先に送る**：「◯◯社の△△です。ご応募ありがとうございます。これからお電話します」→ これだけで応答率が変わる。
- **留守電は必ず残す**。会社名・どの求人か・折り返し先・いつ折り返せばいいか（「本日20時まで、明日は10時から」）。無言で切ると不審番号として着信拒否される。
- **3回で切り上げる**。以降はSMSとメールで待つ。しつこい架電は逆効果。**深夜・早朝はかけない**。

**電話の中身（スクリプト）**

1. 名乗る（会社名＋担当者名）
2. **どの求人への応募かを言う**（複数応募しているので、求職者側も特定できていない）
3. 長くしない。**目的は面接日程を決めることだけ**
4. 条件のすり合わせを電話で全部やろうとしない。会って話す
5. 日程は **「明日の◯時か、明後日の◯時はいかがですか」の二択**。「ご都合のよい日を」は決まらない
6. 最後に **来社方法と持ち物**、そして「**当日でも変更できます**」と言う（辞退ではなくリスケにするため）

**測る**

- **応募当日に架電できた件数の割合**をKPIにする。これが上がると、後段の実施率が全部上がる。
- 誰がいつ何回架電したかを記録する。担当者が変わると二重架電と放置が起きる。
- **前日リマインド**（電話またはSMS）でキャンセルが目に見えて減る。

→ ここに自社実績（§10-1：返信が翌日→1時間になった前後の実施率）を当てる。**この1枚だけで参加者は元が取れる。**

### 6-8. 面接・面談のハードルを下げる（0.5分）

- Web面談可・私服可・**15分のカジュアル面談**から。
- 来社を前提にしない（現地集合、店舗見学だけ、など段階を作る）。
- Bタイプは「登録」という言葉を先に出さない。**まず案件の話をする**。

### 6-9. Bタイプ向け：集客用途で使うときの追加論点（1.5分）

Aタイプにも「紹介会社がどう動いているか」の理解として効くので飛ばさない。

- **「登録すればお仕事を紹介します」型の原稿はCVRが低い**。求職者は登録したいのではなく仕事を決めたい。**具体案件ベース（職種・勤務地・給与）で出し、その先に登録がある**構成にする。§3-1 の「実在しない求人」リスクも同時に下がる。
- **段が1つ多い分、離脱が二重**。追うべきは応募数ではなく `応募 → 連絡つく → 登録面談実施 → 紹介 → 決定` の各率。**どこが一番低いかを1回測る**だけで打ち手が決まる。
- **スピードがAタイプより効く**（§6-7）。
- **法令・規約（要確認の上で必ず触れる）**
  - 有料職業紹介事業は厚労大臣の許可事業。**許可番号・事業者名の明示**が求められる。募集主が誰なのかを曖昧にしない。
  - **求職者から手数料を取らないこと**の明示。
  - Indeed 側の掲載ポリシーは **実在する求人であること**が前提。登録者募集型・派遣登録型の表現は審査で落ちることがある。**掲載可否と表現の制約は最新のポリシーを必ず確認**。
  - 断定せず「直近で運用している範囲ではこうだが、ポリシーは変わるので確認を」と言う。**規制の話で不正確だと一発で信頼を失う。**
- 許容CPAはAより桁が違う（決定単価が大きいぶん応募単価も張れる）。§4-2 に戻して数値例を見せる。

### 6-10. （任意）外国人採用の1枚

人手不足職種の聴衆が多いなら入れる。時間が押したら落とす。

- 応募母集団そのものが国内人材だけでは埋まらない局面がある。
- 求人票を **やさしい日本語** にすると、外国人だけでなく若年層・未経験層の応募も増える（難しい熟語と重ねた敬語を削る）。
- **在留資格ごとに就労の可否と時間制限が違う**。「外国人歓迎」と書く前に、自社の職種で就労できる資格を確認する。**国籍で絞る書き方はしない**（§3-3）。必要な資格の記述にする。
- 採用後の定着（生活支援・行政手続き・言語）まで設計しないと、早期離職で成果単価が跳ね上がる。

### 6-11. よくある失敗トップ5（0.5分・まとめスライド）

1. 1つの求人に全職種を詰め込む
2. タイトルが「アットホームな職場です」
3. 給与が「応相談」
4. **応募への連絡が翌日以降（＋電話していない）**
5. 掲載しっぱなし（運用ゼロ・止まっているのに気づかない）

## 9. 登壇・資料づくりのチップス

- 30分＝スライド15〜20枚が上限。1枚1メッセージ。読ませるスライドは作らない。
- **banリスクを冒頭に置く効果**：以降の「1求人1職種」「事実で書く」が、コツではなくリスク管理として聞かれる。ただし**脅しで終わらせない**。§3 の締め（「止まらない作業＝いい求人を書く作業」）で必ず前向きに着地させる。
- **事前に実際の検索結果画面を用意**（想定エリア・想定職種）。ライブ検索は通信と表示揺れのリスクがあるのでスクリーンショット推奨。生々しさが説得力になる。
- 混在聴衆なので **A / B マーク**をスライド隅に。
- §4-2 の **30秒ワーク**は必ず入れる。集中が戻り、式が記憶に残る。
- 事例は「◯◯業・従業員◯名・エリア」まで具体化。**母数を必ず言う**（「3社の事例です」と正直に言う方が、盛った平均より信用される）。
- 停止事例を話すときは **社名が分からない粒度に丸める**。「◯◯業の数十名規模の会社で」で十分。
- 仕様・法令の最新性は **登壇前日にもう一度確認**（Indeed の掲載ポリシーと紹介事業者向けの扱い、労働条件明示ルール、年齢・性別の制限禁止）。

各事例に `業種・規模・エリア・期間・母数` を添える。

### 10-2. 単価レンジ — §5-4 に1枚

- 職種別の **採用単価／決定単価**
- 繁忙期と閑散期の比較が出せるなら入れる

### 10-3. 歩留まりのベンチマーク — §4-1 と §6-9 に
- Aタイプ：`応募 → 連絡つく → 面接設定 → 面接実施 → 入社` の各率
- Bタイプ：`応募 → 連絡つく → 登録面談実施 → 紹介 → 決定` の各率
- **これが出せると「自社は平均より低い/高い」が参加者の手元で判断できる**。最も持ち帰り価値が高い

### 10-4. 計算式の実例 — §4-2 に
- Aタイプの数値例（応募→入社率、1人あたり粗利）
- Bタイプの数値例（応募→決定率、1決定あたり手数料）

### 10-5. 停止・非表示の実例 — §3-1 に1〜2件
- 止まった原因 → 影響（何日止まった／応募が何件失われた）→ 復帰までの対応
- **社名が分からない粒度に丸める**
