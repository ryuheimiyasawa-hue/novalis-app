# 採用セミナー（30分）構成案 — Indeed 中心

_対象時間: 30分（Q&A別枠）／目的: **情報提供**（売り込みではない）_

---

## 0. 前提

### 聴衆は2タイプ混在

| タイプ | Indeed の使い方 | 応募の先にあるもの |
|---|---|---|
| **A. 経営者陣** | 自社の採用 | 応募 → 面接 → 入社 → 定着 |
| **B. 人材紹介会社** | 求職者の集客 | 応募 → 登録面談 → 求人紹介 → 決定 |

**この2タイプを分けて2本の話にしてはいけない**。30分では持たないし、どちらの参加者も半分しか聞かなくなる。

### 貫くフレーム（導入で宣言する）

> **「表示されて、クリックされて、応募されるまでは、AもBも完全に同じ話です。違うのは応募の“後ろ側”だけです」**

- 第1部・第2部・第3部前半（原稿・タイトル・給与・運用）は **完全に共通**。
- 分岐するのは **応募後のファネル** と **許容単価の計算式**。ここだけ「Aの場合／Bの場合」で並べて見せる。
- この宣言を冒頭に置くと、混在聴衆でも全員が最後まで自分の話として聞ける。

### 目的が「情報提供」であることの設計への影響

- 自社紹介は **30秒**。締めの売り込みも **1分以内、1回だけ**。
- 代わりに **持ち帰り資料の質**に全振りする。参加者が翌日1人で実行できる状態がゴール。
- 「個別相談」は押さない。**置いておくだけ**（資料の最終ページに1行）。情報提供型のセミナーは、売り込まないほうが後から相談が来る。

### 数字の扱い

- 実データを出せるので、**目安ではなく実測を主役にする**（§9 に必要な数字のリストを用意）。
- ただし Indeed の仕様・課金メニュー・審査基準・無料掲載の露出条件は変更が早い。資料には **「◯年◯月時点」** を入れ、単価相場は「当社支援実績のレンジ」と限定する。
- 法令（職業安定法の明示義務、労働条件明示ルール）は **登壇前日に一次情報で再確認**。特にBタイプ向けの内容は規制が絡む。

## 2. 導入（0:00–2:00）

### 話すこと

1. 自己紹介30秒（社数・職種・エリアの3点だけ）。
2. **聴衆の前提を先に言い当てる**：「今日は自社で採りたい方と、紹介事業の集客で使っている方がいらっしゃいます」→ §0 の共通フレームを宣言。
3. 問いかけ：**「自社の求人を、いま、スマホで求職者と同じ言葉で探して、見つけられますか？」**
   - 出てこないなら原稿の巧拙以前に露出がゼロ。最後の3ステップで回収する。
4. 今日持ち帰る3つ：
   1. 応募が来ない理由は **表示・クリック・応募・応募後の4段のどこか** に必ず分解できる
   2. **払っていい応募単価は、自社の数字から計算できる**（相場から入らない）
   3. **応募後1時間以内の返信**が、広告費より効く

### 登壇チップス

- 30分で冒頭に会社紹介を長くやると、そこで離脱される。「今日は網羅しません。3つだけです」と宣言するとメモの取り方が変わる。

## 3. 第1部：採用の原理原則（2:00–8:00）

### 3-1. 求人広告はマーケティングと同じ構造（1.5分）

求職者＝顧客、求人票＝商品ページ、面接／登録面談＝商談。

```
                       表示（インプレッション）
                         → クリック
                           → 応募            ← ここまでA・B共通
                             ↓
        ┌────────────────────┴────────────────────┐
   【A 自社採用】                          【B 紹介会社の集客】
   連絡がつく                               連絡がつく
     → 面接設定 → 面接実施                    → 登録面談の設定 → 登録面談実施
       → 内定 → 承諾 → 入社                    → 求人紹介 → 企業面接 → 決定
         → 定着（3ヶ月・1年）                     → 入社後フォロー
```

**言い切るポイント**：「応募が来ない」という相談の実態は、多くが「応募は来ているが、その先で落ちている」。Bタイプは段が1つ多いので、**同じ応募数でも成果が出にくい構造**になっている。だから後段の歩留まりを見ていない状態で予算を増やすのが、いちばん金を捨てる。

### 3-2. ★許容応募単価を自分で計算する（3分／ワーク込み）

このセミナーで一番持ち帰り価値が高いパート。**相場を聞きに来た人に、計算式を渡して帰す。**

**共通の式**
```
応募1件の価値 = 1件の成果額 × 応募→成果の転換率
許容応募単価（CPA）= 応募1件の価値 × 許容率（例 20〜30%）
```

**Aタイプ（自社採用）の入れ方**
```
1件の成果額 = その人が1年で生む粗利（または採用できないことで失う額）
転換率       = 応募 → 入社 の率
```
- 例の作り方：応募10件で1人入社（10%）、1人が年間で生む粗利が◯◯万円 → 応募1件の価値は◯◯円 → 許容CPAは◯◯円。
- 「採れないことで失う額」で計算させると経営者陣に刺さる（機会損失・既存社員の残業代・断った案件）。

**Bタイプ（紹介会社の集客）の入れ方**
```
1件の成果額 = 1決定あたりの手数料
転換率       = 応募 → 決定 の率（段が多いので Aより一桁小さくなる）
```
- 例の作り方：手数料が1決定◯◯万円、応募100件で◯件決定（◯%）→ 応募1件の価値は◯◯円 → 許容CPAは◯◯円。
- **ここでBタイプの参加者は自分の数字を知らないことが多い**。「応募→登録面談実施率」「登録→決定率」を出せないなら、そこが最初の宿題。

**30秒ワーク**：手元の紙に「1件の成果額」「転換率」だけ書き出してもらう。中盤に手を動かさせると集中が戻る。

**締めの一言**：「相場より高いか安いかは意味がありません。**自社の許容単価より高いか安いか**だけです」

### 3-3. 採用競合は同業他社ではない（1分）

- 求職者から見た競合は **同じ商圏・同じ給与帯の全求人**。飲食の競合はコンビニでも倉庫でもある。
- Bタイプはさらに **紹介会社同士でクリック単価を押し上げ合っている**（同じ求職者を同じキーワードで取り合う）。だからBは単価競争ではなく原稿とスピードで勝つしかない。
- **実際の検索結果画面を見せる**のが最も効く（スクショ推奨。§8）。

### 3-4. 「採用できない」の8割は人物像が決まっていない（0.5分）

要件を3つに割る。Must が5個以上なら、それは採用ではなく奇跡待ち。

| 区分 | 内容 | 例 |
|---|---|---|
| Must | ないと採用しない | 週4日以上・土日どちらか出勤可 |
| Want | あると嬉しい | 経験1年以上・普通免許 |
| Negative | あると採らない | 直近3年で短期離職3社以上 |

## 4. 第2部：媒体の地図とIndeedの位置づけ（8:00–14:00）

### 4-1. 媒体は5種類しかない（2分）

| 種類 | 例 | 課金 | 向き |
|---|---|---|---|
| 求人検索エンジン | Indeed / 求人ボックス / スタンバイ | クリック課金が中心 | 常時募集・複数職種・地場・**集客用途** |
| 求人サイト | タウンワーク / マイナビ系 / doda 等 | 掲載課金 | 短期集中・ブランドのある募集 |
| 人材紹介 | エージェント | 成果報酬（理論年収の3割前後） | 採用難職種・急ぎ・少数 |
| ダイレクト・SNS | スカウト媒体 / X / Instagram | 月額＋工数 | 母集団が薄い職種・認知 |
| リファラル・ハローワーク・自社サイト | — | ほぼ無料 | 土台。放置されがち |

**言い切るポイント**：課金形態が違うだけで、全部「求職者との接点を買う」こと。値段ではなく **募集の頻度** で選ぶ。年1回なら掲載課金、年中募集ならクリック課金。

> Aタイプへの補足：この表の「人材紹介」は、今日の聴衆のBタイプがやっている事業。**採用チャネルとして併用する前提で話す**と、会場が対立しない。

### 4-2. なぜ Indeed から始めるのか（2分）

1. **求職者の入口としての規模**。求人サイトに載せた求人も、結局 Indeed 経由で見られていることが多い。
2. **クリック課金なので少額から始めて止められる**。掲載課金と違い、失敗が1ヶ月固定されない。
3. **無料掲載の枠がある**（露出は絞られる傾向。最新条件は要確認）。0円で原稿の型を作れる。
4. **数字が見える**。表示・クリック・応募が見えるので、第1部のファネル分解がそのまま運用になる。

正直に言うべきこと：**Indeed は仕様変更が早い**。無料掲載の見え方、課金メニュー、審査基準は都度変わる。「◯年◯月時点」と添えて、細かい最新仕様は質問で受ける。ここで見栄を張ると信頼を落とす。

### 4-3. 掲載の2経路（1分）

- **直接投稿**：Indeed 上で求人を作成。今日から始められる。まずこれ。
- **サイト連携（クロール）／ATS連携**：自社採用サイトの求人を拾わせる。自由度と資産性が高いが立ち上げに時間がかかる。
- 順番は **直接投稿で勝ちパターンを作る → 採用サイトに移す**。逆をやると、効果の出ない採用サイトに数十万円かける。

### 4-4. 費用の考え方（1分）

- クリック単価は職種・エリア・時期で大きく動く。**見るべきは単価ではなく応募単価と成果単価**（第1部の計算式に戻す）。
- 1〜3月・9〜10月は求人が増えて競合が強くなる。**採りたい時期の1ヶ月前に原稿を仕上げる**。
- ここに **自社支援実績のCPAレンジ**を職種別で出す（§9-2）。実データが最も効くスライド。

## 5. 第3部：Indeed 実践施策（14:00–26:00）★本編

### 5-0. ★全体の見方：3段＋1の分解（1.5分）

**配布資料の目玉。「どこが悪いか」は数字で必ず分かると伝える。**

| 症状 | 見る数字 | 原因の在り処 | 触る場所 |
|---|---|---|---|
| そもそも表示されない | 表示数 | 検索に引っかかっていない／予算 | 職種名・勤務地・予算 |
| 表示はされるがクリックされない | CTR | 一覧画面で選ばれていない | タイトル・給与・会社名の見え方 |
| クリックされるが応募されない | 応募率（CVR） | 詳細ページで離脱 | 本文冒頭・写真・応募フォーム |
| 応募は来るが成果にならない | A: 面接実施率／B: 登録面談実施率・決定率 | 応募後の対応 | 返信速度・日程調整・ミスマッチ |

- **触る順番を間違えないこと**：`原稿 → 対象の拡大（勤務地/雇用形態/時間帯/給与レンジ）→ 予算`。**予算増額は最後**。
- ここに自社支援実績の改善事例（§9-1）を1つ当てる。「CTRが◯%→◯%に上がって表示単価が下がった」等。

### 5-1. 掲載の型（1分）

- **1求人＝1職種＝1勤務地**。「ホール・キッチン・配達スタッフ募集！」は検索に当たらず、クリックの質も落ちる。
- 複数店舗・複数エリアは分けて出す。勤務地は **番地まで**（エリア検索・通勤時間の絞り込みに効く）。
- 同一内容のコピー投稿はしない（重複判定で出なくなる）。分けるなら中身も変える。

### 5-2. タイトルが9割（2分）

型：**【職種名】＋【雇用形態】＋【勤務地】＋【訴求を1つだけ】**

- 良い例：`調理補助（パート）／◯◯市△△町・週3日〜・未経験可`
- 悪い例：`一緒に働きませんか？アットホームな職場です！！`
  - 「アットホーム」「明るい職場」は検索されない語。1文字も仕事をしていない。
- **求職者が検索する語を使う**：「軽作業」「ホールスタッフ」「2tドライバー」「介護職員初任者研修」。社内呼称（「サービスクルー」等）は通じない。
- 記号の乱用・過剰な煽り・絵文字は避ける（審査・品質の観点で不利）。
- 訴求は1つに絞る。3つ入れると何も残らない。

### 5-3. 給与欄（1.5分）

- **「応相談」「当社規定による」は最悪手**。給与での絞り込み検索から丸ごと外れる。
- 必ず数値、かつ幅で（例：時給1,150円〜1,400円）。幅の上限には根拠（経験・資格）を添える。
- 月給の場合、**固定残業代は時間数と金額を明記**。訴求以前に法令上の明示事項。
- 2024年の労働条件明示ルール改正で、**就業場所・業務の変更の範囲**の明示なども必要になった。求人票の記載要件は登壇前に一次情報で再確認する。
- 「昇給あり」より「入社1年で時給+50円が◯%」。**数字と実績で書く**。

### 5-4. 本文の並び順（2分）

求職者の意思決定順に並べる。これがそのまま本文構成。

1. **勤務地**（通えるか）→ 2. **給与**（生活できるか）→ 3. **時間・シフト**（続けられるか）→ 4. **仕事内容**（できるか）→ 5. **人・雰囲気**（安心か）

- **冒頭150文字で「誰に・何を・いくらで」を言い切る**。スマホで最初に見えるのは数行。会社沿革から始めない。
- 効くブロック：`1日の流れ`／`入社後3ヶ月のイメージ`／`よくある質問`／`先輩の声`。
- **ネガティブ情報を先に出す**（体力を使う／土日出勤あり／立ち仕事）。応募数は少し減るが、**後段の実施率と定着率が上がって成果単価は下がる**。第1部のファネルに接続して説明する。
- 写真は**実際の職場・実際の人**。ストックフォトは見抜かれる。動画は差がつく。

### 5-5. 応募フォームの摩擦（0.5分）

- 追加質問は **3つまで**。多いほど落ちる。
- **「履歴書必須」は応募率を大きく下げる**。書類は面談時でよい。
- 応募完了後の自動返信に **次に何が起きるか**（誰から・いつ・どの手段で連絡が来るか）を書く。不安による辞退が減る。

### 5-6. 運用（1.5分）

- 予算は1職種あたり少額の日予算で **2週間テスト**。効果のない原稿に予算を足しても効果は出ない。
- **触るのは1回1箇所**。タイトルと本文と予算を同時に変えると、何が効いたか分からない。
- **週1回15分の定例**で数字を見る（表示・クリック・CTR・応募・CPA）。運用しているかどうかが最大の差。
- 企業の口コミ評価は放置しない。応募直前に見られている。

### 5-7. 応募後（最大の投資対効果）（1.5分）

- **1時間以内に連絡**。求職者は複数社に応募していて、最初に返事をした会社が有利。翌日連絡は半分に減る前提。
- 電話に出ない層には **SMS／メッセージアプリ**。開封率が違う。
- 日程調整は「ご都合のよい日を」ではなく **「明日の◯時か、明後日の◯時はいかがですか」**。選ばせる。
- **前日リマインド**でキャンセルが目に見えて減る。
- ハードルを下げる：Web面談可・私服可・15分のカジュアル面談から。
- ここに自社実績（§9-1の返信速度と実施率の相関）を当てる。**この1枚だけで参加者の元は取れる。**

### 5-8. Bタイプ向け：集客用途で使うときの追加論点（2分）

Aタイプにも「紹介会社がどう動いているか」の理解として効くので、飛ばさない。

- **「登録すればお仕事を紹介します」型の原稿はCVRが低い**。求職者は登録したいのではなく、仕事を決めたい。**具体案件ベース（職種・勤務地・給与）で出し、その先に登録がある**構成にする。
- **段が1つ多い分、離脱が二重**。追うべきは応募数ではなく `応募 → 連絡つく → 登録面談実施 → 紹介 → 決定` の各率。**どこが一番低いかを1回測る**だけで打ち手が決まる。
- **応募後のスピードがAタイプより効く**。求職者は複数の紹介会社に同時登録している。先に面談を組んだ会社の案件で決まる。
- **法令・規約まわり（要確認の上で必ず触れる）**
  - 有料職業紹介事業は厚労大臣の許可事業。**許可番号・事業者名の明示**が求められる。募集主が誰なのかを曖昧にしない。
  - 求職者から手数料を取らないことの明示。
  - Indeed 側にも掲載ポリシーがあり、**実在する求人であること**が前提。登録者募集型・派遣登録型の表現は審査で落ちることがある。掲載可否と表現の制約は **最新のポリシーを必ず確認**。
  - ここは断定せず「直近で運用している範囲ではこうだが、ポリシーは変わるので確認を」と言う。**規制の話で不正確だと一発で信頼を失う。**
- **許容CPAの計算はAより桁が違う**（決定単価が大きいぶん、応募単価も張れる）。第1部の計算式に戻して、Bタイプの数値例を見せる。

### 5-9. よくある失敗トップ5（0.5分・まとめスライド）

1. 1つの求人に全職種を詰め込む
2. タイトルが「アットホームな職場です」
3. 給与が「応相談」
4. 応募への連絡が翌日以降
5. 掲載しっぱなし（運用ゼロ）

### 5-10. （任意）外国人採用の1枚

人手不足職種の聴衆が多いなら入れる。押したら落とす。

- 応募母集団そのものが国内人材だけでは埋まらない局面がある。
- 求人票を **やさしい日本語** にすると、外国人だけでなく若年層・未経験層の応募も増える（難しい熟語と重ねた敬語を削る）。
- **在留資格ごとに就労の可否と時間制限が違う**。「外国人歓迎」と書く前に、自社の職種で就労できる資格を確認する。
- 採用後の定着（生活支援・行政手続き・言語）まで設計しないと、早期離職で成果単価が跳ね上がる。

## 8. 登壇・資料づくりのチップス

- 30分＝スライド15〜20枚が上限。1枚1メッセージ。読ませるスライドは作らない。
- **事前に実際の検索結果画面を用意**（想定エリア・想定職種）。ライブ検索は通信と表示揺れのリスクがあるのでスクリーンショット推奨。生々しさが説得力になる。
- 混在聴衆なので、スライドの隅に **A / B のマーク**を入れると迷子が出ない。共通パートは両方点灯。
- 中盤（§3-2）の **30秒ワーク**を必ず入れる。集中が戻るのと、計算式が記憶に残る。
- 事例は「◯◯業・従業員◯名・エリア」まで具体化する。
- 実データを出すときは **母数を必ず言う**（「3社の事例です」と正直に言う方が、盛った平均より信用される）。
- 仕様・法令の最新性は **登壇前日にもう一度確認**（Indeed の掲載メニューと紹介事業者向けポリシー、労働条件明示ルール）。

## 9. 実データの差し込み先（出せる数字のリスト）

実績が出せるので、**どのスライドにどの数字を入れるか**を先に決める。ここが埋まると説得力が別物になる。

### 9-1. 改善事例（Before / After）— 第3部に3つ当てる
| 差し込み先 | 欲しい数字 |
|---|---|
| §5-0 3段分解 | タイトル改善前後の **表示数・CTR** |
| §5-3 給与欄 | 「応相談」→ 数値明記での **応募数の変化** |
| §5-7 応募後 | 返信が翌日→1時間になった前後の **面接／登録面談の実施率** |

各事例は `業種・規模・エリア・期間・母数` を添える。

### 9-2. 単価レンジ — §4-4 に1枚
- 職種別の **応募単価（CPA）レンジ**（支援実績の実測）
- 職種別の **採用単価／決定単価**
- 「時期による変動」を示せるなら繁忙期と閑散期の比較

### 9-3. 歩留まりのベンチマーク — §3-1 と §5-8 に
- Aタイプ：`応募 → 連絡つく → 面接設定 → 面接実施 → 入社` の各率
- Bタイプ：`応募 → 連絡つく → 登録面談実施 → 紹介 → 決定` の各率
- **これが出せると「自社は平均より低い/高い」が参加者の手元で判断できる**ので、最も持ち帰り価値が高い

### 9-4. 計算式の実例 — §3-2 に
- Aタイプの数値例（応募→入社率、1人あたり粗利）
- Bタイプの数値例（応募→決定率、1決定あたり手数料）
