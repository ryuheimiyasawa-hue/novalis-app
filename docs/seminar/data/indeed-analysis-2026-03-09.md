## 注意（読むときの前提）

- **CPA は 費用÷応募数 で自前計算**。レポートの「応募単価（CPA）」列は応募0のとき0と表示され、
  費用が出ているのに0円に見えるため使っていない。
- **1行＝1求人×1エリア×1掲載期間**。掲載期間の長さが行ごとに違うので、行単位のCPAは
  期間の影響を受ける。比較の主役は「費用1万円以上の求人」の表にすること。
- 費用が少額の行のCPAは不安定（応募1件でCPAが決まる）。母数を必ず併記する。
- **eishin は4ファイルに含まれていない。**
- 「株式会社ノヴァリス」（199行）と「株式会社ノヴァリス(自社雇用)」（1行）が別アカウントとして
  存在する。どちらが自社採用ぶんかは要確認。
