# 匿名化データ（配布用）

`python3 docs/seminar/data/export_anonymized.py <out_dir> <csv>...` で生成。

| ファイル | 内容 | 配布 |
|---|---|---|
| `jobs_anonymized.csv` | 求人ごとの集計 72件（CPA昇順） | ○ |
| `areas_anonymized.csv` | 都道府県×市区町村ごとの集計 31件 | ○ |
| `summary_anonymized.csv` | 全体のファネルと主要指標 | ○ |
| `_company_map.csv` | ラベルと実際の社名の対応 | **× 社内用** |

- 社名は費用の大きい順に `A社`〜`H社`。配布用3ファイルに実社名は含まれない（生成時に検査済み）。
- `母数条件を満たす` = 1 は「表示1,000回以上 または 応募10件以上」を満たす32求人。
  スライドや外部説明ではこの32件だけを使う。0 の求人はCPAが不安定。
- 率（応募率・CTR・応募完了率）は小数。パーセント表記は各自で変換すること。
- **採用数はIndeedのレポートに含まれないため、採用単価は算出できない。応募単価までが範囲。**
