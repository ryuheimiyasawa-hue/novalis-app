# Indeed 実績データの集計

セミナーで出す定量データ（応募数・広告費・CPA）を、企業 × 職種 × エリアで集計する。

## 手順

1. `cpa-intake-template.csv` に実績を貼る（1行＝1求人、または1求人×1期間）
2. `python3 analyze_cpa.py <csv>` で集計表を出す

```
python3 docs/seminar/data/analyze_cpa.py docs/seminar/data/cpa-intake-template.csv > /tmp/out.md
```

## 列の説明

| 列 | 必須 | 備考 |
|---|---|---|
| 企業 | ○ | ノヴァリス自社雇用 / eishin / aitane / ゼンシック / NINEJAPAN など |
| 職種 | ○ | 求人票のタイトルではなく、集計したい職種名に寄せる（例「介護職員」） |
| エリア | ○ | 市区町村まで。エリア比較の粒度がそろっていないと比較にならない |
| 期間開始 / 期間終了 | 推奨 | 期間がそろっていない行を混ぜると CPA が比較できない |
| 表示回数 | 任意 | あると CTR が出る。無ければ空欄 |
| クリック数 | 任意 | あると 応募率(CVR) と CPC が出る |
| 応募数 | ○ | これが無い行は自動で除外される |
| 広告費 | ○ | 円。スポンサー費用（消化額）。無い行は自動で除外される |
| 採用数 | 任意 | あると採用単価が出る。セミナーでは CPA より効く |

## 出力される表

- 全体サマリ（応募数・広告費・CPA・採用単価）
- 企業別 / 職種別 / エリア別 / 職種×エリア / 明細
- **同一職種の中での CPA のひらき（倍率）** — セミナーで一番効く数字。
  「同じ職種・同じエリアでも、原稿と運用で CPA は◯倍ひらく」と言える

## 注意

- 率はすべて各括りの合計から算出（単純平均ではなく加重平均）
- **顧客企業の実績を外部セミナーで出す場合は、匿名化と許諾を確認する**。
  社名を出さず「◯◯業・従業員◯名規模」に丸めるのが安全
- 母数を必ず併記する。求人数が2〜3件の括りを「傾向」として語らない
