# スライド作成プロンプト（Codex 用）

添付する3ファイル: `jobs_anonymized.csv` / `areas_anonymized.csv` / `summary_anonymized.csv`
（`docs/seminar/data/anonymized/`。`_company_map.csv` は渡さない）

---

```text
採用セミナー（30分）のスライドを作ってください。デザインはあなたに任せます。

━━━━━━━━━━━━━━━━━━━━━━
■ 成果物
━━━━━━━━━━━━━━━━━━━━━━
・16:9 のスライド、**10〜12ページ**
・単一の HTML ファイル（ブラウザで開いて発表でき、印刷でPDF化できるもの）。
  PowerPoint(.pptx) のほうが良いと判断すればそれでも構いません
・1ページ1メッセージ。文字を読み上げるだけのページは作らない
・グラフ・図は添付CSVの数値から作る。数字を創作しない
・発表者ノート（各ページで話すこと、3〜5行）を付ける

━━━━━━━━━━━━━━━━━━━━━━
■ 聴衆と目的
━━━━━━━━━━━━━━━━━━━━━━
・聴衆: 自社で採用したい経営者。採用専任がいない会社が中心
・目的: 情報提供。売り込みではない。最後の売り込みは1行だけ
・持ち時間30分。Q&Aは別枠

━━━━━━━━━━━━━━━━━━━━━━
■ 絶対に守ること
━━━━━━━━━━━━━━━━━━━━━━
1. **企業名・個人名を一切書かない。** CSVの「A社」等のラベルも
   スライドには出さない（社数を語るときは「支援先8社」のように件数で書く）
2. **数字は添付CSVの値のみ。**相場や業界平均を創作しない。
   出典として「当社支援実績 2026年3月〜9月」と各ページに小さく入れる
3. **母数の弱い数字を主役にしない。**`jobs_anonymized.csv` の
   `母数条件を満たす` が 1 の **32求人だけ**を分析に使う。0 の求人は使わない
   （応募1件でCPAが決まってしまうため）
4. **採用単価は出せない。**Indeedのレポートに採用数が無い。応募単価(CPA)までに留める
5. **法令・規約に触れるページには「2026年◯月時点。最新はIndeedの規約と
   所管法令を必ず確認」と明記**する。条文番号は書かない
6. 「アットホームな職場」のような中身のない語を良い例として出さない
7. 脅しで終わるページを作らない。必ず打ち手に着地させる

━━━━━━━━━━━━━━━━━━━━━━
■ 伝えたいコアメッセージ（これが全体の背骨）
━━━━━━━━━━━━━━━━━━━━━━
**「採用したい職種を直接集めようとしない。集客しやすい職種で人を集め、
  まず会社に興味を持ってもらい、そこから職種を提案する。」**

この結論に至る論理を、データで順番に積み上げてください:

(1) Indeed に来る求職者は、職種を指名して探しているより、
    条件（勤務地・給与・未経験可・休日）で選んでいる層が多い。
    転職の情報収集の仕方に慣れていない人の比率が相対的に高い
    → **これは登壇者の実務経験にもとづく見解。データでは示せないので、
      「実感」「経験則」として提示する**（断定しない）
(2) だから採りたい難職種を求人名で直接指名しても集まらない。
    データ: 営業職の1求人は費用40,788円で応募3件（CPA 13,596円、応募率1.2%）。
    表示は2,366回出ていたので、露出ではなく訴求の問題
(3) 逆に集客しやすい職種は10分の1以下で集まる。
    データ: 上位は 227円 / 266円 / 272円 / 286円 / 323円（事務・マーケ・広報系）
    母数条件を満たす32求人で **最安227円〜最高13,596円、約60倍のひらき**
(4) つまり「入口の職種」と「最終的に任せる職種」を分けて設計する。
    入口で集めて、会社の魅力で惹きつけ、面談の中で職種を提案する
(5) **業務委託枠で募集するのも有効。**優秀な人が入ってくるケースが多い
    → これも登壇者の経験則。データは補強材料として:
      業務委託3求人のCPAは522円（正社員787円より安い）。
      ただし**3求人しかないので傾向とは言えない**と正直に添える

━━━━━━━━━━━━━━━━━━━━━━
■ もう一つのテーマ: Indeed の掲載停止（BAN）リスク
━━━━━━━━━━━━━━━━━━━━━━
**止まったら原稿の出来も予算も全部ゼロになる**、という位置づけで扱う。

・**最大のリスクは求職者からのクレーム。**応募したのに連絡が来ない、
  書いてある条件と違う、といった不満が積み上がると掲載に影響する。
  → 打ち手は「応募に必ず、早く返信する」。落選連絡も出す。
    書いた条件を守る。これはBAN対策と採用成果の両方に効く
・**年齢制限を求人票に書かない。**性別・国籍で絞る書き方もしない。
  法令上も原則禁止（最新の要件は必ず確認）
・実態と違う条件を書かない（歩合の上限を月収として書くなど）
・1求人に複数職種を詰めない。募集終了した求人は必ずクローズする
・Indeed 1媒体に依存しない。止まった日に採用が完全停止しない状態を作る

━━━━━━━━━━━━━━━━━━━━━━
■ ページ構成（10〜12ページ。増減の提案は歓迎）
━━━━━━━━━━━━━━━━━━━━━━
P1  自己紹介（簡易でよい。名前・会社・やっていること・支援実績の規模の4点）
    ※ 具体的な社名や個人名は入れず、プレースホルダにしてください
P2  今日持ち帰る3つ
    ① 採りたい職種を直接集めない ② 応募後の返信が広告費より効く
    ③ 止まらないための運用（BAN対策）
P3  今日のデータの前提
    2026年3月〜9月／72求人／表示131,115回／クリック17,786／応募1,200件／
    費用957,873円／全体CPA 798円。社名は非公開。分析は母数条件を満たす32求人
P4  Indeedに来る層の特性（＝経験則として提示）
    職種指名ではなく条件で選ぶ。だから「待つ」設計は当たらない
P5  採りたい職種を直接指名した結果（失敗の実例）
    費用40,788円 → 応募3件 / CPA 13,596円 / 応募率1.2% / 表示2,366回
P6  集客しやすい職種は10分の1以下
    32求人のCPA一覧（グラフ推奨）。最安227円〜最高13,596円＝約60倍
P7  CPAを決めているのはクリック単価。応募率ではない
    上位はCPC 40円以下。応募率は下位のほうが高いケースもある
    → 「原稿が悪い」と決めつける前に、どの段で落ちているかを見る
P8  ★コアメッセージ（この1枚が本題）
    集客職種で集める → 会社に興味を持ってもらう → 職種を提案する
    入口の職種と最終的な職種を分ける、というフロー図
P9  業務委託枠という打ち手
    優秀な層が拾える（経験則）＋ 業務委託3求人のCPA 522円（母数注記つき）
P10 BANリスク①: 一番危ないのは求職者からのクレーム
    応募への返信ルール。落選連絡も出す。書いた条件を守る
    ＋ 応募0のまま消えた費用151,126円（全費用の15.8%）を添える
P11 BANリスク②: 年齢制限を書かない・規約を守る
    NG表現の例と言い換え。1求人1職種。募集終了はクローズ。1媒体依存を避ける
P12 明日からの3ステップ ＋ 連絡先（売り込みは1行）
    ① 自社求人を求職者と同じ検索語でスマホで探す
    ② 入口の職種を決め直す（採りたい職種と分ける）
    ③ 応募には1時間以内に返信するルールを作る

  求人ごとの集計72件。CPA昇順。
```

## 補足（プロンプトには含めない、宮澤さん向けメモ）

- **「レイヤーが低い」という表現はスライドに書かないほうがいい**です。資料は残って
  人手に渡るので、求職者を下に見る表現だと取られると一発で損をします。
  プロンプトでは「職種を指名して探すより条件で選ぶ層が多い」「転職の情報収集に
  慣れていない人の比率が相対的に高い」という事実ベースの言い方に置き換えました。
  口頭で補足するぶんは自由ですが、紙に残す言葉は変えておくのが安全です。
- P4 と P9 は**データで示せない主張**なので、「経験則として提示する」ことを
  プロンプトで明示しています。ここを断定すると、データ部分の信頼も落ちます。
- P1 の自己紹介は社名・個人名をプレースホルダにさせています。Codex に本名を
  渡す必要はなく、出てきた枠に後から埋めれば済みます。
