■ 最初に説明すること: Indeedの費用は何で決まるのか

以下は当社アカウントの実データから検証した内容:

・**課金はクリックに対して発生する（クリック課金）。表示だけでは課金されない。**

・**予算は「上限」として働く。**期間と金額を決めると、その範囲で消化される。
  上限に達すれば止まり、届かなければ余る。
  実データ: 予算10万円のキャンペーンは費用ちょうど100,000円で打ち止め。
  予算25,000円のものも25,000円で到達。一方、予算30,000円で費用13,711円しか
  使われず余ったキャンペーンもある
・**1クリックの値段（CPC）は自社で決め切れない。**同じ求職者を狙う他社との
  競合で動く。職種・エリア・時期で変わる。
  実データ: 全体のCPCは54円（行ごとの中央値86円）。
  事務・マーケ系は7〜30円、北海道の営業職は269〜873円
  → **同じ予算でも、取れるクリック数が職種で10倍以上違う**
・ここから導かれる示唆（後のコアメッセージへの伏線にする）:
  **予算を増やすより、CPCの安い入口を選ぶほうが効く**
・**日額予算を絞ると、クリック単価そのものが下がる。**予算を上げると単価の高い
  枠まで買いに行くため、CPCが上がる。安く集めたいなら日額を小さくして走らせる

・**Indeed PLUS にも触れる（2024年1月開始）。**Indeedに出した求人が

・**予算の設定方法**: 「平均日額」と「月額」の2パターン。

・**行ごとのCPCを入札単価として語らないこと。**クリック数が1〜3件の行では

■ コストを抑える実務Tips: 日額予算を小さくして並列に走らせる
━━━━━━━━━━━━━━━━━━━━━━
**「安く集めたいなら、日額予算を300円くらいに絞った求人を複数並べて走らせる」**

・仕組み: 予算を上げると、Indeedは単価の高い掲載枠まで買いに行くのでCPCが上がる。
  逆に**日額を絞ると安いクリックから拾う**ため、CPCが下がる
・当社データでの検証（**これは説明の根幹なのでスライドに必ず載せる**）:
  ① 1掲載あたりの費用帯別（266行を集計）
     費用1〜499円の行 … **CPC 27円 / CPA 375円**
     費用1,500〜2,999円の行 … **CPC 93円 / CPA 1,183円**
     費用3,000〜5,999円の行 … **CPC 104円 / CPA 1,222円**
  ② ①だけだと「安い職種が低予算帯に偏っている」可能性があるので、
     **同じ求人の中で**費用の小さい掲載と大きい掲載のCPCを比べた。
     **24組のうち17組で、費用の小さい掲載のほうがCPCが安かった。**
     例（同一求人・同一原稿）: 費用50円の掲載はCPC17円、費用18,460円の掲載はCPC738円
     → 職種の違いではなく、**予算の出し方でCPCが動いている**
・**必ず添える注意（これを省くと誤解を生む）**:
  低予算だと1掲載から出る応募の絶対量は少ない。費用1〜499円の54掲載で
  応募は32件（1掲載あたり0.6件）。
  → **「安く集める」には効くが「今月5人採る」には足りない。**
    急ぎの採用は別途まとまった予算が必要。だから
    **低額を並列に多数走らせて母集団を作り、採りたい枠には予算を寄せる**
    という二段構えにする
・運用上の注意: 求人数が増えるぶん管理が煩雑になる。通知と集計の自動化
  （後述のAI活用ページ）とセットで初めて回る

■ 第2のメッセージ: 見るべき指標は応募単価ではなく「面接着座単価」
━━━━━━━━━━━━━━━━━━━━━━
・採用単価を本気で下げたいなら、応募単価より
  **「面接に座ってもらうまでの単価（面接着座単価）」**のほうが重要。
  応募が安く集まっても、連絡がつかず面接に来なければ1円も回収できない
・**応募直後の電話がここに最も効く。**採用目的でも有効。
  応募ボタンを押した直後が一番熱い。複数社に応募しているので
  最初に電話が通じた会社が面接に進む
・打ち手の具体: 1時間以内（理想は5分）／出ない前提で時間帯を変えて2〜3回／
  在職者は昼休みと18〜20時／知らない番号には出ないのでSMSを先に送る／
  留守電は必ず残す（会社名・どの求人か・折り返し先・いつ折り返せるか）／
  日程は「明日の◯時か明後日の◯時」の二択／前日リマインド
・**面接着座単価は今回のデータからは算出できない**（面接数がレポートに無い）。
  だから「自社で測ってください」という形で提示し、計算式だけ渡す:
      面接着座単価 = 広告費 ÷ 面接実施数
      応募 → 連絡がつく → 面接設定 → 面接実施 の各率を1回測る
・参考として出せるデータ: 応募開始1,440件に対し応募完了1,200件（完了率83.3%）。
  **応募フォームの段階で240人が消えている。**着座の前段でも漏れている

■ 第3のメッセージ: AI活用（自社の実例）
━━━━━━━━━━━━━━━━━━━━━━
**「クリエイティブは人が考えて作る必要がある。一方で分析と返信はAIで
  だいぶ良くなった。」**という切り分けを軸にする。

自社で実際にやっていること（※具体的な構成の詳細は登壇者が口頭で補足するので、
スライドでは仕組みの概要にとどめ、詳細はプレースホルダにしてください）:
・**Indeedの応募への自動返信**。応募が入ったら即座に一次返信が飛ぶ。
  前述の「1時間以内」を人手に頼らず担保できる
・**Slackへの応募通知**。誰の受信箱にも埋もれず、当番で誰でも拾える状態を作る
・**AIによる求人原稿のA/Bテスト**。タイトル・冒頭文の案を出させて回し、
  数字で残ったものを採用する
・切り分けの整理:
    人がやること   … 訴求の発明、会社の魅力の言語化、写真・動画、面接での動機づけ
    AIに任せること … 応募の一次返信、通知と割り振り、原稿案の量産、数字の集計と異常検知
・**AIは「速さ」と「漏れのなさ」を担保する道具**。
  ゼロから刺さる訴求を作るのはまだ人、という線引きを明確に伝える

■ 第4のメッセージ: Indeed の掲載停止（BAN）リスク
━━━━━━━━━━━━━━━━━━━━━━
**止まったら原稿の出来も予算も全部ゼロになる**、という位置づけで扱う。

・**最大のリスクは求職者からのクレーム。**応募したのに連絡が来ない、
  書いてある条件と違う、といった不満が積み上がると掲載に影響する。
  → 打ち手は「応募に必ず、早く返信する」。落選連絡も出す。書いた条件を守る。
    **これはBAN対策と面接着座単価の改善が同じ打ち手になる**という点を強調する
・**年齢制限を求人票に書かない。**性別・国籍で絞る書き方もしない。
  法令上も原則禁止（最新の要件は必ず確認）
・**自社ホームページが重要。**事業内容が確認できるホームページが無い、
  あるいは**掲載している求人がホームページ上の事業内容と合っていない**と、
  掲載を止められる可能性がある。求人を出す前にホームページ側を整える
・実態と違う条件を書かない（歩合の上限を月収として書くなど）
・1求人に複数職種を詰めない。募集終了した求人は必ずクローズする
・Indeed 1媒体に依存しない。止まった日に採用が完全停止しない状態を作る

## 補足（プロンプトには含めない、宮澤さん向けメモ）

- **「レイヤーが低い」という表現はスライドに書かないほうがいい**です。資料は残って
  人手に渡るので、求職者を下に見る表現だと取られると一発で損をします。
  プロンプトでは「職種を指名して探すより条件で選ぶ層が多い」「転職の情報収集に
  慣れていない人の比率が相対的に高い」という事実ベースの言い方に置き換えました。
  口頭で補足するぶんは自由ですが、紙に残す言葉は変えておくのが安全です。
- **面接着座単価は今回のデータからは出せません**（Indeedのレポートに面接数が無い）。
  P9・P10 は計算式と測り方を渡す構成にしてあります。もし社内に
  「応募→面接実施率」や「架電当日実施率」の実数があるなら、そこだけ差し込めば
  このパートが一気に強くなります。出せる数字があれば教えてください。
- **AI施策（P11〜P13）の具体は渡していません。**自動返信の文面、Slack通知の作り、
  A/Bテストの回し方は、スライドではプレースホルダになります。見せられる範囲の
  スクリーンショットや実際の改善数値があれば、この3枚が本セミナーの差別化点に
  なります。
- P4 / P10 / P13〜P15 の一部は**データで示せない主張**なので、「経験則として提示」を
  プロンプトで明示しています。ここを断定すると、データ部分の信頼も落ちます。
- **P3（料金の仕組み）は、お預かりしたデータでの検証＋公開情報の確認の両方にもとづきます。**
  クリック0で費用が出ている行は0行、応募0で費用が出ている行は85行・151,126円
  （全行クリックあり）。よって「クリック課金である」と言い切れます。
  予算上限の挙動も、キャンペーン名の金額と実費用の一致から確認しました。
  公開情報でも「有料掲載（スポンサー求人）はクリック課金で、請求は
  クリック単価×クリック回数。予算上限に達すると有料掲載が停止」と一致しました。
  **訂正**: 私は当初「応募課金・採用課金のプランも存在する」と申し上げましたが、
  調べた範囲ではクリック課金が基本で、応募課金の存在を確認できませんでした。
  プロンプトからその記述を外しています。
  なお **Indeed PLUS**（2024年1月開始／連携媒体への自動配信）も
  クリック課金のままなので、P3に1行入れる指定にしました。
- **日額予算のTips（P8）は、データで裏づけが取れました。**費用帯別だと
  「安い職種が低予算帯に偏っているだけ」の可能性が残るので、**同一求人内で
  費用の大小を比較**する検証も入れてあります（24組中17組で低費用側のCPCが安い）。
  ここまでやっておくと、突っ込まれても答えられます。
  同時に「量は出ない」という限界も必須記載にしました。低予算だけを勧めると
  「言われた通りやったのに採用できない」になるので。
- ご依頼のあった「データの前提」ページは削除しました。代わりに、数字を使う各ページの
  隅に出典（当社支援実績・期間・母数）を小さく入れる指定にしています。
