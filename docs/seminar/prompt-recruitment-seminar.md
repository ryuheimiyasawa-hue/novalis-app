# 採用セミナー台本生成プロンプト（自社採用に特化）

聴衆は「自社で採用したい経営者」に一本化。人材紹介会社の集客用途は扱わない。
`【 】` を書き換えて使う。空欄のまま投げても、仮定を明示して書き切るよう指示してある。

---

## A. 本体プロンプト（このまま貼る）

```text
あなたは求人広告運用と採用支援の実務経験が豊富なコンサルタントです。
私がこれから登壇する採用セミナーの「話す台本」を作ってください。

━━━━━━━━━━━━━━━━━━━━━━
■ 案件情報
━━━━━━━━━━━━━━━━━━━━━━
・持ち時間: 30分（Q&Aは別枠）
・テーマ: Indeed を中心とした自社採用の進め方
・目的: 情報提供。売り込みではない。個別相談への送客は最小限でよい
・形式: 【対面 / ウェビナー】
・スライド: 【作る / 作らない（口頭のみ）】
・登壇者（私）の立場: 【 例: 採用支援会社の代表 】

・聴衆: 自社で採用したい経営者。採用専任の担当者がいない会社が中心
・聴衆の主な業種: 【 】
・想定人数: 【 】
・聴衆の習熟度: 【 Indeedは使ったことがあるが、運用（数字を見て直す）はしていない層 】
・聴衆が採用したい職種: 【 】

・出せる実データ: 【 例: 支援◯社の職種別CPAレンジ、タイトル改善前後のCTR、
  返信速度と面接実施率の相関、掲載停止の実例 】
  ※ データは私が後から埋めるので、台本には「ここに入れる」プレースホルダを置いてほしい

━━━━━━━━━━━━━━━━━━━━━━
■ 貫く設計思想（ここは崩さない）
━━━━━━━━━━━━━━━━━━━━━━
1. 「求人を出す話」で終わらせない。採用は
   〈求人を出す → 応募が来る → 面接する → 入社する → 定着する〉まで1本の線。
   経営者が本当に困っているのは応募より後ろ側なので、後半を厚くする。

2. 流れは「抽象 → 媒体 → 施策」。ただし冒頭に掲載停止リスクを置く。
   運用の巧拙より「止まらないこと」が先だと最初に言うと、以降の
   「1求人1職種」「事実で書く」がコツではなくリスク管理として聞かれる。

3. 細かいチップスを密度高く入れる。抽象論で終わらせない。
   参加者が翌日1人で実行できる状態がゴール。

4. 経営者向けなので、必ず「社長自身が何をするか」に落とす。
   担当者に任せる話ではなく、社長が今週やることとして書く。

5. 目玉スライドを4枚作り、配布資料でも独立した1枚ものにする:
   (1) 掲載が止まる代表パターン＋予防チェックリスト
   (2) 許容採用単価の逆算（1人採れないと、いくら損しているか）
   (3) 「3段＋1」分解（どこが悪いかを数字で切り分ける表）
   (4) 応募後の架電フロー（時間帯・回数・スクリプト）

━━━━━━━━━━━━━━━━━━━━━━
■ 時間配分（合計30分。変えるなら理由を添えて提案して）
━━━━━━━━━━━━━━━━━━━━━━
0:00–2:00   導入: 今日持ち帰る3つ
2:00–5:00   第0部: 止まったら全部ゼロ（掲載停止・アカウント停止）
5:00–11:00  第1部: 採用の原理原則（ファネル分解／許容採用単価／要件定義）
11:00–14:30 第2部: 媒体の地図と Indeed の位置づけ
14:30–21:00 第3部: 求人を出す側の施策（掲載・タイトル・給与・本文・運用）
21:00–26:00 第4部: 応募が来てから入社・定着まで（電話・面接・承諾・初期定着）
26:00–29:00 まとめ: 明日からの3ステップ
29:00–30:00 持ち帰り資料の案内・Q&A導線

━━━━━━━━━━━━━━━━━━━━━━
■ 各パートに必ず入れる要素
━━━━━━━━━━━━━━━━━━━━━━
【導入】
・自己紹介は30秒（社数・職種・エリアの3点のみ）
・問いかけ:「自社の求人を、いま、求職者と同じ言葉でスマホで探して見つけられますか？」
  → 最後の3ステップで回収する
・「今日は網羅しません。3つだけ持って帰ってください」と宣言
・今日持ち帰る3つ:
  1) 止まるリスクを先に潰す。運用の巧拙より、止まらないことが先
  2) 1人採れないことで失っている額は計算できる。そこから払える金額が決まる
  3) 応募後の電話が、広告費より効く

【第0部 掲載停止リスク】
・止まる代表パターンを表で（募集していない求人の出しっぱなし／重複投稿／複数職種の
  詰め込み／タイトルの煽り・記号／実態と異なる条件（歩合の上限を月収として書く）
  ／年齢・性別・国籍の制限表現／応募フローを迂回する外部誘導／多重アカウント・
  再登録／募集終了の放置）
・アカウント単位で止まると全職種の応募が0になる。止まるのは繁忙期。復帰は即日でない
・「表示が急に落ちたら、原稿を直す前に停止・非表示を疑う」
・法令が絡む部分（年齢制限の原則禁止、性別制限の原則禁止、国籍で絞らない、
  労働条件の明示）は必ず触れる。ただし条文の断定はせず「要確認」と明示
・予防チェックリスト（掲載前チェックシート／NGワードを機械的に潰す／投稿経路を
  1本に統一／募集終了は必ずクローズ／外部誘導しない／止まったら1箇所ずつ直して
  再申請、全面書き直しはしない／Indeed 1本足にしない）
・脅しで終わらせず、この一言で着地させる:
  「止まらないための作業は、全部“いい求人を書くための作業”と同じです」

【第1部 原理原則】
・求人広告はマーケティングと同じ構造。求職者＝顧客、求人票＝商品ページ、面接＝商談
・ファネルを最後まで引く:
  表示 → クリック → 応募 → 連絡がつく → 面接設定 → 面接実施 → 内定 → 承諾 →
  入社 → 定着（3ヶ月・1年）
・「応募が来ない」という相談の実態は、多くが「応募は来ているが、その先で落ちている」
  と指摘する。応募→面接実施が5割を切っていたら広告費の半分を捨てている
・許容採用単価を経営者の言葉で逆算させる（相場を答えない）:
    1人採れないことで失う額 = 売上機会 ＋ 既存社員の残業代 ＋ 断った案件
                              ＋ 疲弊による離職リスク
    1人が1年で生む粗利 → ここから許容採用単価 → 応募→入社率で割って許容応募単価
・30秒の書き出しワークを入れる（「1人採れないと、ひと月いくら失っているか」だけ書かせる）
・締め:「相場より高いか安いかは意味がない。自社の許容単価より高いか安いかだけ」
・採用競合は同業他社ではなく、同一商圏・同一給与帯の全求人。
  飲食の競合はコンビニでも倉庫でもある
・条件の市場適合を正直に言う:
  「同じ商圏の同じ職種を10件見てください。自社が下のほうなら、原稿では勝てません」
  時給を上げるかどうかは経営判断だが、まず事実を見る
・定着は採用と同じ財布。1人辞めなければ1人採らなくていい。
  早期離職が出ると採用単価は実質2倍
・採用要件を Must / Want / Negative に割る（Mustが5個以上なら採用ではなく奇跡待ち）

【第2部 媒体】
・媒体は5種類（求人検索エンジン／求人サイト／人材紹介／ダイレクト・SNS／
  リファラル・ハローワーク・自社サイト）。課金形態と向き不向きを表で簡潔に
・選ぶ基準は値段ではなく「募集の頻度」。年1回なら掲載課金、年中ならクリック課金
・なぜIndeedから始めるか4点（求職者の入口としての規模／少額で始めて止められる／
  無料枠で原稿の型を作れる／数字が見えるのでファネル分解がそのまま運用になる）
・掲載の2経路（直接投稿 / 自社採用サイト連携・ATS連携）。順番は直接投稿で
  勝ちパターンを作ってから採用サイトへ。逆をやると効果の出ない採用サイトに
  数十万円かける。両方やると重複事故になるので経路は1本
・費用はクリック単価ではなく応募単価と採用単価で見る。
  1〜3月と9〜10月は求人が増えて競合が強いので、採りたい時期の1ヶ月前に原稿を仕上げる

【第3部 求人を出す側の施策】
・冒頭に「3段＋1」分解の表を置く:
    表示されない → 職種名・勤務地・予算・掲載状態
    クリックされない（CTR）→ タイトル・給与
    応募されない（CVR）→ 本文冒頭・写真・応募フォーム
    応募は来るが採用に至らない → 電話・面接・条件（第4部へ）
  触る順番は「掲載状態の確認 → 原稿 → 対象の拡大 → 予算」。予算増額は最後
・1求人＝1職種＝1勤務地。複数店舗は店舗ごとに出す。勤務地は番地まで
・タイトルの型:【職種名】＋【雇用形態】＋【勤務地】＋【訴求を1つだけ】
  求職者が検索する語を使う。社内呼称（「サービスクルー」等）は通じない。
  「アットホーム」は1文字も仕事をしていない、と言い切る
・給与は必ず数値＋幅。上限には根拠（経験・資格）を添える。
  「応相談」は絞り込み検索から丸ごと外れる。
  固定残業代は時間数と金額を明記。歩合の上限を月収として書かない。
  「昇給あり」より「入社1年で時給+50円が◯%」と実績で書く
・本文は求職者の意思決定順（勤務地→給与→シフト→仕事内容→人）。
  冒頭150文字で「誰に・何を・いくらで」を言い切る。会社沿革から始めない
・効くブロック: 1日の流れ／入社後3ヶ月のイメージ／よくある質問／先輩の声
・ネガティブ情報を先に出す（体力を使う・土日出勤あり・立ち仕事）。
  応募は減るが面接実施率と定着率が上がって採用単価は下がる
・写真は実際の職場・実際の人。ストックフォトは見抜かれる
・応募フォームの追加質問は3つまで。履歴書必須は応募率を大きく下げる。
  自動返信に「これから◯◯（担当者名）よりお電話します」と書く
・運用: 少額の日予算で2週間テスト／触るのは1回1箇所／週1回15分の定例で
  表示・CTR・応募・CPA・掲載状態を見る／企業口コミを放置しない

【第4部 応募が来てから入社・定着まで】※ここを厚く
・★応募後の電話:
  - つかみ:「広告費を1円も増やさずに採用数を増やす方法が1つだけあります」
  - なぜ効くか: 応募ボタンを押した直後が一番熱い／複数社に同時応募していて
    最初に電話が通じた会社が勝つ／電話はその場で日程が決まる唯一の手段
  - スピード基準: 1時間以内、理想は5分
  - 出ない前提の設計: 1回目でつながるのは半分以下／時間帯を変えて2〜3回／
    在職者は昼休みと18〜20時／SMSを先に送ってから架電／留守電は必ず残す
    （会社名・どの求人か・折り返し先・いつ折り返せばいいか）／3回で切り上げ／
    深夜早朝はかけない
  - スクリプト: 名乗る→どの求人への応募か言う→目的は日程だけ→条件交渉は
    会って→「明日の◯時か明後日の◯時」の二択→持ち物と「当日でも変更できます」
  - 体制: 採用専任がいない前提で書く。応募通知を共有の受信箱／Slack／LINEに
    飛ばして当番制にする。社長1人の受信箱に入れると、社長が動けない日の応募が死ぬ
  - KPIは「応募当日に架電できた件数の割合」。架電記録を残す（担当が変わると
    二重架電と放置が起きる）。前日リマインドでキャンセルが減る
・面接（経営者向けにここを具体的に）:
  - 面接は選考ではなく相互の動機づけ。話す／聞くを半々にする
  - 会社側から「なぜあなたに来てほしいか」を言う。これを言わない会社が多い
  - 中小企業の最大の武器は社長が出てくること。社長が15分出るだけで承諾率が変わる
  - ハードルを下げる: Web面談可・私服可・15分のカジュアル面談から・店舗見学だけ
  - 面接辞退を防ぐ: 前日リマインド、当日の変更を歓迎する言い方、道順と目印
・内定・オファー:
  - 口頭で終わらせず、条件を書面で即日出す（給与・勤務時間・休日・試用期間）
  - 辞退の理由は給与より「不安」。不安は情報で消す。
    現場を見せる、一緒に働く社員と話させる、初日の流れを先に伝える
  - 迷っている人に期限だけ切らない。次の接点（見学・社員との面談）を作る
・入社後（早期離職＝採用単価2倍）:
  - 初日の受け入れを決めておく（誰が迎えるか、席と道具、初日の終わりに一言）
  - 1週間後・1ヶ月後・3ヶ月後の1on1をカレンダーに先に入れる
  - 求人票は既存社員も読んでいる。書いたことを守れないと社内が冷える
・よくある失敗トップ5でまとめる（全職種を1求人に詰める／タイトルが「アットホーム」
  ／給与が応相談／応募への連絡が翌日以降で電話していない／掲載しっぱなしで
  止まっているのに気づかない）

【まとめ】
・明日からの3ステップ（すべて社長自身がやること）:
  1) 自社の求人を求職者と同じ検索語でスマホで探す（5分）。
     出てこなければ露出ゼロ、または止まっている
  2) タイトルと給与欄だけ直す＋NGワードチェック（30分）
  3) 「応募には1時間以内に電話する」を社内ルールにする（0円）。
     誰が・いつ・何を言うか、出なかったら何時にかけ直すかまで決める
・締め:「予算を増やす前に、この3つを全部やってください。順番が逆だと、
  同じ失敗に金を払うことになります」

━━━━━━━━━━━━━━━━━━━━━━
■ 絶対に守る制約
━━━━━━━━━━━━━━━━━━━━━━
1. 数字は断定しない。相場を語らず「当社支援実績（◯年◯月時点）」と限定する。
   母数を添える書き方にする
2. Indeed の仕様・課金メニュー・審査基準・無料掲載の露出条件は変わる前提で書く。
   「◯年◯月時点」と添え、細かい最新仕様は質問で受ける建てつけにする
3. 法令に触れる箇所は条文番号を断定せず、「登壇前日に一次情報で再確認」と
   台本の注記に入れる。特に年齢・性別・国籍の制限、労働条件の明示
4. 売り込みは最後の1回・1分以内。実質は資料の最終ページに1行置くだけにする
5. 中身のない語（「アットホーム」「明るい職場」「やりがい」）を良い例として
   出さない。悪い例として使う
6. スライドは15〜20枚が上限。1枚1メッセージ。読ませるスライドは作らない
7. 掲載停止の事例は社名が分からない粒度に丸める（「◯◯業の数十名規模の会社で」）
8. 脅しや煽りで終わるパートを作らない。必ず打ち手に着地させる
9. 「条件を上げれば採れる」で片付けない。かつ「原稿だけで何とかなる」とも言わない。
   市場と合っていない条件は事実として指摘し、判断は経営者に委ねる書き方にする
10. 人材紹介会社の集客用途、派遣、登録者募集の話は入れない。自社採用に絞る

━━━━━━━━━━━━━━━━━━━━━━
■ 出力してほしいもの（この順で）
━━━━━━━━━━━━━━━━━━━━━━
1. タイムテーブル表（時間・パート・狙い）
2. スライド一覧（番号／タイトル／そのスライドの1メッセージ／割り当て時間）
3. パートごとの台本。話し言葉で書く。言い切るフレーズは太字。
   スライド番号と対応させる。「ここで実データを入れる」プレースホルダを明示
4. 配布資料4点セットの中身（3段＋1分解／許容採用単価の計算シート／掲載前チェック
   シート（NGワード表＋必須記載項目）／タイトルの型＋架電フロー）
5. 想定Q&Aと回答（最低7問。「クリック単価の相場は？」には相場を答えず
   許容単価の話に戻す回答を用意。「時給を上げないと無理では？」「電話をかける
   人手がない」「ハローワークとの使い分け」も入れる）
6. 事前準備チェックリスト（検索結果のスクショ、確認すべき最新仕様と法令、
   実データの整理、リハーサルで測る時間）
7. 私に足りていない情報の質問リスト（最大5つ。台本を良くするために必要な順）

━━━━━━━━━━━━━━━━━━━━━━
■ 進め方
━━━━━━━━━━━━━━━━━━━━━━
・【 】が空欄の項目は、もっとも一般的な想定を仮定として明示した上で書き切ること。
  質問して止まらない
・30分に収まるかを最後に自己チェックし、オーバーしていれば削る候補を3つ挙げる
```

## B. テコ入れ用の追い込みプロンプト（本体の後に投げる）

```text
■ 厚さを変える
```

## C. 使い方のメモ

- **A を投げる前に `【 】` を埋める**。特に「聴衆の主な業種」「採用したい職種」
  「出せる実データ」の3つで出力の質が大きく変わる。職種が決まるとタイトル例と
  検索キーワードが一気に具体化する。
- 実データは後から埋める前提でプレースホルダを置かせているので、**Aの時点で
  数値を用意しなくてよい**。
- 厚めに出させて **B で削る**ほうが30分に収まりやすい。
- 制約3番（法令の一次情報確認）、7番（社名を丸める）、9番（条件の話を逃げない）は
  消さないこと。ここを外すと登壇時のリスクと、聴衆の不信につながる。
